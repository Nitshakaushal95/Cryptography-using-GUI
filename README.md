# 🔐 Caesar Cipher — Cryptography Tool

A simple yet elegant **Caesar Cipher** desktop application built with Python and Tkinter.  
Encode and decode messages using a customizable shift value through a clean, dark-themed GUI.


---

## ✨ Features

- 🔒 **Encode** any text using Caesar Cipher
- 🔓 **Decode** any Caesar-encrypted message
- 🔢 **Custom shift value** (1–25) via a spinbox
- 📋 **Copy to clipboard** with one click
- 🗑️ **Clear** input/output instantly
- 🖥️ Clean dark-themed GUI built with Tkinter
